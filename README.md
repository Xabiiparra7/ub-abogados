# UB Abogados — Laura Urriza Balda

Landing page de un solo scroll para el despacho de Laura Urriza Balda (UB Abogados), especializado en Derecho Laboral en Navarra.

## Contenido

- `index.html` — estructura de la página.
- `styles.css` — estilos.
- `script.js` — pequeño script (año dinámico en el footer).

## Ver la página localmente

Abre `index.html` en el navegador, o sirve la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```
